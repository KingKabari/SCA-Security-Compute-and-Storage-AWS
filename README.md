# SCA-Security-Compute-and-Storage-AWS
This repo is to assess whether students can identify poor design choices and improve them

## Student Task
Given this scenario:
A company uses one AWS root account for daily operations, allows SSH from anywhere (0.0.0.0/0), stores backups in S3 without thinking about access controls, and shares one login across the team.

### Write an essay that:
1. Identifies the risks in this setup
2. Recommends better practices
3. Explains how IAM, roles, and Security Groups should be used
4. Explains how SSH access should be handled securely
5. Explains how S3 access should be controlled

### Diagram Requirement
Redraw the environment to show a more secure architecture.

### Deliverables
1. 600–900 word essay
2. One corrected architecture/security diagram
   
## Note
Refer to the essay for detailed explanations of design decisions, security considerations, and service configurations.
